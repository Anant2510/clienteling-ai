v1.0 · SOLUTION OVERVIEW

Autonomous personalization, end to end.

Not a chatbot bolted onto a storefront. A live agent that reads real customer context — orders, addresses, inventory, store locations — and acts across browse, cart, fulfillment and post-purchase. It drives the page, not just the conversation.
Track 01 · Browse

Persona-aware discovery

  • Same catalog, a different ordering per shopper — premium-led, value-led, or deal-led.
  • Product-page module swaps per customer; merchandiser-overridable from an AI console.
  • Hero, copy and assistant tone re-curate live on identity switch.
  • Assistant cites real past purchases by name — grounded, not hallucinated.
Track 02 · Cart

Fulfillment-aware UI

  • Delivery promise from the shopper's stored ZIP → nearest store → live inventory.
  • Add-to-cart flips to "In cart · Remove" when an item is present.
  • Per-identity cart persistence survives switching and email round-trips.
  • The assistant drives the page: search, filter, add, remove, checkout — from one prompt.
Track 03 · Autonomous lifecycle HEADLINE

An agent that works without you.

  • In-session agent watches the cart, detects hesitation, escalates in stages.
  • Server-side cron agent continues the journey even after the tab is closed — reading the same shared state.
  • Stage 1: an AI-drafted nudge in the customer's voice. Stage 2: an incentive with a one-click accept link.
  • Click the link → state updates → the offer is already applied the instant they return to the cart. No reload.
  • A demo time-warp lever compresses hours into seconds so the full lifecycle plays on stage in under two minutes.
Track 04 · Disruption

Decision-tree recovery

  • Configurable delay per order; the agent picks the remedy from live inventory + address:
  • Short delay → email offers in-store pickup: nearest store, address, hours.
  • Long delay → AI-drafted alternate product with an accept-CTA. One click cancels the original and reorders — the agent restructures the order for the customer.
  • Out of stock → email presents both: pick up locally OR ship an alternate.
Track 05 · Closed loop

Every action enriches the next.

  • Orders placed in-app write back to the commerce platform via its Admin API.
  • Inventory decrements; delivery promises reflect the new stock.
  • Order history grows; the assistant's next reply references the just-placed order.
  • Self-signup creates a real customer in real time — personalization begins on the first click.

Common questions

Which commerce platforms?Adapter-based. The demo runs Shopify-native (Storefront + Admin APIs); the same interface maps to other platforms.
Which AI model?Model-agnostic via a secure proxy — no model keys ever reach the browser. Swap providers without touching the storefront.
Does it act, or just chat?It acts: drives the page, places orders, cancels + reorders on disruption, applies incentives — all through real APIs.
How does it work after the tab closes?An in-session agent syncs cart state to a shared store; a server-side cron agent continues the lifecycle independently.
Is personalization real-time?Yes — identity switches and new signups re-curate the whole storefront immediately from the live customer record.
Production-readiness?The demo uses time-compression and sandbox email for stage clarity; production swaps in real cadences, a verified sending domain, and signed links.
